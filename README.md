플루오레세인 형광 분석 웹앱 (임시 저장 버전)
기능
사진 업로드 및 ROI 영역 지정
평균 G 밝기, 최대 G 밝기, 포화 픽셀 비율 계산
ROI 표시 사진 및 분석 결과 CSV 다운로드
농도 선정 조건 판정
pH 및 완충용액 실험 그래프
현재 세션 동안의 기록 갤러리
저장 관련 주의
이 버전은 Supabase 등 외부 데이터베이스를 사용하지 않습니다. 기록은 현재 Streamlit 세션에만 임시 저장되며, 앱 재실행 또는 세션 초기화 후 사라질 수 있습니다. 필요한 기록은 CSV, JSON, 사진으로 직접 다운로드해 보관하세요.
실행
requirements.txt의 패키지를 설치한 뒤 다음 명령으로 실행합니다.
streamlit run app.py
