🧪 플루오레세인 나트륨 형광 분석 웹앱
플루오레세인의 형광 사진을 분석하고, pH 변화 및 완충용액 실험 결과를 기록·비교하는 실험용 웹 애플리케이션입니다.
주요 메뉴
1. 농도 선정
사진 업로드와 분석을 한 화면에서 진행
분석 영역(ROI) 설정
평균 G 밝기, 최대 G 밝기, 포화 픽셀 비율 계산
밝기 범위, 포화도, 배경과의 차이, 반복 안정성 기준 확인
2. pH 기준시료-형광
pH와 농도 등 시료 정보 입력
사진 분석 및 결과 저장
저장된 실제 측정값으로 pH-형광 밝기 그래프 생성
3. 완충용액-형광
pH, 농도, 첨가물(HCl/NaOH 등), 첨가량 입력
사진 분석 및 결과 저장
저장된 실제 측정값으로 첨가량-형광 밝기 및 pH-형광 밝기 그래프 생성
사진 분석 방법
각 실험 메뉴 안에서 사진을 업로드하고 ROI를 조정한 뒤 결과를 확인합니다. 사진 분석을 위해 별도 메뉴로 이동할 필요가 없습니다.
그래프 안내
그래프는 임의의 예시 데이터로 미리 채워져 있지 않습니다. 실험 메뉴에서 측정값을 저장하면 현재 세션에 저장된 실제 측정값을 바탕으로 그래프가 나타납니다. 아직 데이터가 없으면 안내 문구만 표시됩니다.
데이터 저장 안내
외부 데이터베이스를 사용하지 않는 임시 저장 버전입니다. 기록은 현재 Streamlit 세션에서만 유지되며, 앱이나 세션이 초기화되면 사라질 수 있습니다. 중요한 결과는 CSV, JSON 및 사진으로 다운로드해 별도로 보관하세요.
