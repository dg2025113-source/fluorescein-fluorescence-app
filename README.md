🧪 플루오레세인 형광 분석 웹앱

플루오레세인의 형광 사진을 분석하고, pH 변화에 따른 형광 세기를 비교할 수 있는 실험용 웹 애플리케이션입니다.

✨ 주요 기능

1. 형광 사진 분석

- 형광 사진 업로드
- 분석 영역(ROI) 지정
- 평균 G 채널 밝기 측정
- 최대 G 채널 밝기 및 포화 픽셀 비율 계산
- 분석 영역과 결과 사진 확인

2. 농도 선정

- 농도별 측정 결과 비교
- 밝기, 포화도, 배경과의 차이 및 반복 측정 안정성 확인
- 실험에 적합한 농도 선정 지원

3. 실험 데이터 시각화

- pH에 따른 형광 세기 그래프
- 완충용액 실험 결과 그래프
- 측정값의 변화와 경향 분석

4. 실험 기록 및 데이터 다운로드

- 현재 세션에서 분석 결과 임시 저장
- 저장된 결과 확인
- CSV 및 JSON 형식으로 데이터 다운로드
- 필요한 사진을 별도로 저장하여 보관

💾 데이터 저장 안내

이 웹앱은 외부 데이터베이스를 사용하지 않는 임시 저장 방식입니다.

- 기록은 현재 앱 세션에서만 유지됩니다.
- 앱을 다시 실행하거나 세션이 초기화되면 저장한 기록이 사라질 수 있습니다.
- 중요한 실험 결과는 CSV, JSON 및 사진 파일로 다운로드하여 별도로 보관해 주세요.

🛠️ 사용 기술

- Python
- Streamlit
- Pandas
- Pillow
- Matplotlib

🚀 실행 방법

필요한 패키지를 설치한 후 터미널에서 다음 명령어를 실행합니다.

pip install -r requirements.txt
streamlit run app.py

🎯 프로젝트 목적

플루오레세인의 형광 발광 특성을 활용하여 pH 변화와 완충용액의 효과를 탐구하고, 실험 데이터를 시각화하여 화학적 현상을 분석하는 것을 목표로 합니다.
