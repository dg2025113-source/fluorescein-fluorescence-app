Fluorescein Fluorescence Analysis App

플루오레세인 나트륨의 형광 밝기를 측정하고 pH 변화에 따른 형광 특성을 분석하는 과학 탐구 웹앱입니다.

주요 기능

- 형광 사진 업로드 및 분석 영역(ROI) 설정
- 녹색 채널의 평균 밝기 측정
- 농도 선정 조건 확인
- pH와 형광 밝기의 관계 그래프
- 완충용액 실험 결과 시각화
- 분석 데이터 CSV 다운로드
- 사진과 분석 결과 저장 기능

사용 방법

1. 사진을 업로드합니다.
2. 분석할 영역(ROI)을 설정합니다.
3. 형광 밝기를 확인합니다.
4. 실험 데이터를 그래프로 분석합니다.
5. 필요한 데이터를 CSV 파일로 다운로드합니다.

개발 환경

- Python
- Streamlit
- Pandas
- Matplotlib
- Pillow

탐구 목적

플루오레세인 나트륨의 pH에 따른 형광 밝기 변화를 관찰하고, 이를 이용해 산·염기 환경과 완충용액의 특성을 탐구합니다.
